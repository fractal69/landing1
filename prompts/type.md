## Typography System (Mandatory)

Apply a professional typography system based on a **Perfect Fourth (1.333) modular scale**. Do not use arbitrary font sizes. Every text element must follow this mathematical scale to ensure consistency, readability, visual hierarchy, and a premium appearance.

### Typography Scale

| Style | Size |
|-------|------|
| Display XL | 76px |
| Display L | 57px |
| H1 | 43px |
| H2 | 32px |
| H3 | 24px |
| H4 | 18px |
| Body Large | 18px |
| Body | 16px |
| Body Small | 14px |
| Caption | 12px |

### Font Weights

- Display: **700–800**
- H1–H2: **700**
- H3–H4: **600**
- Body text: **400**
- Buttons: **600**
- Labels and UI elements: **500**

### Line Height

- Display: **1.1**
- H1–H2: **1.15**
- H3–H4: **1.25**
- Body text: **1.6**
- Caption: **1.5**

### Vertical Spacing

- After H1: **48px**
- After H2: **32px**
- After H3: **24px**
- Between paragraphs: **16–24px**

### Rules

- Always use the typography scale above.
- Never create arbitrary font sizes.
- Every font size must come from the modular scale.
- Maintain a clear and consistent visual hierarchy across the entire website.
- Do not use font sizes smaller than **16px** for primary reading content.
- Headings must follow the typography scale sequentially without skipping or introducing custom sizes.
- Keep typography consistent across all pages and components.
- Prioritize readability, whitespace, and elegant proportions over decorative styling.
- Aim for a premium, modern aesthetic comparable to high-end architecture, interior design, luxury furniture, and home décor websites.
- If a new typography level is required, derive it mathematically from the **1.333 Perfect Fourth modular scale**, rounding to the nearest whole pixel when necessary.
